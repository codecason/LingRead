# 聆阅 LingRead —— Foxit Reader PDF 朗读助手

为 Foxit Reader 提供 TTS 朗读：从选区首字或点击位置起读、停止、暂停、重读和两字高亮。

- 当前仅实现 edge-tts 在线引擎及缓存，没有接入收费云接口。离线引擎和腾讯云仍是历史设计中的计划，尚未实现。
- 伴侣应用架构，无需 Foxit 官方授权即可使用
- 本次设计与验收边界见 [实现设计](docs/02-实现设计.md)；[原设计](docs/01-设计方案.md)保留作历史资料。

## v0.2.11 修复版

- 自动识别 PDF 路径失败时弹出文件选择框。选择 Foxit 当前打开的同一份 PDF 后，回到正文重新点击或圈选，再点击朗读；无需命令行。关联仅存于当前会话，窗口、进程或标题变化后重新识别。
- 同名标签页无法仅凭标题区分；请避免在同一窗口打开不同目录的同名 PDF。


- 在读取选区和剪贴板之前完成点击坐标换算，防止复制期间的焦点变化使已有效的点击位置丢失。坐标无法匹配时显示具体原因。
- 语音合成前过滤纯标点、空白和控制字符片段，保留后续正文及原有字符索引；真实正文合成失败仍会报错。

- 新增分进程 JSONL 诊断日志，含版本、运行时长、请求和播放会话标识；覆盖选区读取、剪贴板失败原因、坐标匹配、TTS 重试和句间等待。每 30 秒记录资源和状态快照。
- 日志位置及排障方法见 [实现设计：诊断设计](docs/02-实现设计.md#诊断设计)。此版本增加故障证据采集，不宣称已修复长期运行后的识别或云端故障。

- 修复普通中文换行被插入空格、导致词语中间出现额外停顿的问题。合并换行时同步维护字符坐标，保留英文词间空格和标点停顿。

- 页面定位仅由点击 `⌖ 定位` 手动触发。朗读跨页、文字接近边缘或高亮匹配失败时不会自动跳页或滚动，可边听边自由翻阅。

- 点击工具栏的“音色”菜单，可选晓晓、晓伊、云希、云健、Ava、Andrew，或自动随语言选择；设置会保存，下次启动继续使用。
- 播放中切换音色会取消旧音色预取，用新音色重读当前句；暂停时切换保持暂停，点击继续后播放新音色。
- `--voice` 现在对 Foxit 模式和指定 PDF 模式都有效；界面中后续选择的音色优先。
- 窗口、工具栏、托盘和 `--version` 显示当前版本。每次更新交付均注明版本号。

- 修复换到无自定义页码标签的 PDF 后无法读取页码：兼容 `8 / 320`、`531 (551 / 758)` 和纯数字，并校验页码范围。

- 修复点击非激活悬浮条时被当成 Foxit 正文点击、清除朗读起点的问题；增加真实 Qt 按钮及鼠标监听回归测试。
- 读取选区、索引文档和合成语音分别显示进度，索引期间禁止重复触发朗读。
- 启动及朗读诊断写入缓存目录的 `runtime.log`，日志按大小轮转，不记录正文内容。

- 修复滚动到重复字形较多的正文时，页面匹配被误判失败、导致全文无高亮的问题：使用双向特征匹配过滤误匹配，保留原有位置置信度检查。
- 按用户要求移除工具栏的逐词高亮，保留普通播放状态；逐词进度仅用于 PDF 正文上的高亮叠层。正文高亮与自动定位的完整交互验收仍未通过，不以工具栏表现代替验收。
- `⌖ 定位`：手动回到当前音频对应的正文位置，暂停时也可用；定位完成或超时后停止调整视口。

默认启动入口改为单文件 `dist\LingRead.exe`，将 `_cffi_backend` 等音频原生依赖嵌入 EXE。可以单独复制该文件运行；`build` 目录仅是打包中间产物，不是发布入口。仅保留单文件便携版，不再提供安装版。

已实现：

- `TextEngine`：逐字坐标映射、选区定位、句内截断、重复段落消歧。
- `EdgeTTSEngine`：合成与 WordBoundary 时间戳一起缓存。
- `PlaybackController`：句子级播放队列，停止 / 暂停 / 重读 / 续读
- `FoxitBridge`：窗口侦测 + MRU 注册表文档路径解析 + UIA 页码定位
  （已在 Foxit PDF Reader Continuous 版本实测：文档路径、当前页码均正确）
- 悬浮条 UI（无边框置顶、可拖拽）+ 系统托盘
- 中文每两个连续汉字一组，标点处分组；英文按词高亮。暂停冻结高亮，停止清空；重读首个截断句时保留选区起点。
- 本地页面图像匹配恢复滚动、缩放后的页面坐标，无法可靠定位时不绘制错误高亮。截图仅在本机内存使用。

## 使用

1. 运行 `启动聆阅.bat`（使用单文件 `dist\LingRead.exe`，无需另装 Python）。
2. 在 Foxit 的文字选择模式下圈选一段正文，再点击“▶ 从光标读”。从选区首字继续向后朗读；逆向拖选仍从正文顺序的首字开始。
3. 也可以先点击正文，再点击朗读。页内定位失败会提示重新选择，不会静默从页首开始。
4. `⏸` 暂停/继续，`⏹` 停止，`↺` 重读当前句；刚起读的首句保留原选区偏移。
   `⌖ 定位` 回到当前朗读文字，不重新合成或重播音频。

默认缓存位于 `%USERPROFILE%\.lingread`；测试或便携部署可用 `LINGREAD_DATA_DIR` 指定其他目录。扫描件、复杂版面及多版本兼容性仍需专项验收，尚不宣称达到完整 toC 生产验收。

## 运行

```bash
pip install -r requirements.txt

# Foxit 模式：自动侦测 Foxit 窗口，从选区或点击位置朗读
python LingRead.py

# 直读模式（调试）
python LingRead.py --pdf path\to\doc.pdf --page 10

# 无界面冒烟测试
python LingRead.py --pdf tests\fixtures\selection-regression.pdf --headless --max-sentences 2

# 从项目根目录运行离线回归测试
python -m unittest discover -s tests -p test_reading_regressions.py -v

# 单文件便携版（默认启动入口）
python -m PyInstaller --noconfirm --workpath build-standalone LingReadStandalone.spec

```

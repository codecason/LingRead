# 聆阅 LingRead 实现设计

适用版本：v0.2.11。本文合并原对话记录、选区与高亮修复说明、调试日志说明，仅描述当前代码实现。

## 架构与模块

程序是 Windows 上独立运行的 Foxit 伴侣应用。通过窗口接口和 UI Automation 获取阅读上下文，用 PyMuPDF 解析本地 PDF，通过 edge-tts 合成语音，使用 miniaudio 播放，PySide6 提供悬浮条和透明高亮叠层。

| 模块 | 职责 |
| --- | --- |
| `bridge/foxit.py` | Foxit 窗口、文档路径、页码、选区及手动页面操作 |
| `bridge/geometry.py` | PDF 渲染图与阅读器视口匹配、页面和屏幕坐标换算 |
| `text/engine.py` | 文本清洗、句子索引、字符坐标与起读位置解析 |
| `tts/edge.py`、`tts/timing.py` | 在线合成、缓存、词边界与高亮时间片 |
| `player/queue.py` | 合成预取、音频播放、暂停、停止及重读 |
| `ui/reader.py`、`ui/bar.py`、`ui/overlay.py` | 交互调度、播放控制、正文叠层 |
| `diagnostics.py` | 结构化运行诊断与资源快照 |

模块路径均相对于 `src/lingread`。

## 文档与起读位置

1. 识别 Foxit 窗口，结合窗口标题与注册表最近文件记录解析本地 PDF 路径。通过 UI Automation 读取当前页码，兼容普通页码、总页数以及自定义页码标签。
2. PyMuPDF 提取文本及逐字矩形，以句子编号和句内字符偏移表示阅读位点。清洗中文排版换行时同步维护字符坐标，避免词语中间插入额外空格；保留英文词间空格和标点。
3. 鼠标监听保存正文点击锚点，排除悬浮条自身的点击。先完成页面匹配并将点击换算为 PDF 坐标，再获取选区，避免复制过程中的焦点变化使有效点击位置丢失。
4. 选区优先从 UIA TextPattern 获取；不可用时在目标窗口执行受保护的复制，保存并还原可读取的剪贴板格式。
5. 有选区时从选区在正文顺序中的首字起读，结合页码和点击位置消歧；无选区时使用点击位置。选区无法匹配或点击坐标无法可靠换算时显示原因。

首句可以从中间截断，但保留原字符偏移，用于高亮及重读。选区定义起点，朗读会继续向后进行。

## 合成与播放

采用 edge-tts 在线合成，整句音频就绪后解码播放，同时预取后续句子；预取队列容量为两项。音频与 WordBoundary 时间戳共同缓存，缓存键包含引擎标识、音色、语速和文本，SQLite 保存音频缓存索引。

合成支持有限重试及总超时控制。纯标点、空白或控制字符片段在入队前跳过，保留原有句子与字符索引；真实正文合成失败向界面报告。停止操作取消当前会话及合成任务，会话检查防止旧任务继续播放。

悬浮条提供暂停、继续、停止、重读、语速和音色控制。音色设置持久化；播放中切换音色会取消旧预取并从当前句位点重新合成，暂停状态保持不变。

## 正文高亮与手动定位

以播放采样进度推进高亮时间片。中文每两个连续汉字分组，标点处分组，英文按词；词内字符时间由 WordBoundary 时长插值，缺少边界时按音频时长估计。暂停冻结高亮，停止清除高亮，绘制在 Qt 主线程进行。

通过本地 PDF 渲染图与 Foxit 视口图像的特征匹配估计页面变换，再把字符矩形映射到屏幕。匹配置信度不足时隐藏叠层。图像在本机内存中处理。黄色高亮由透明叠层显示，不写入 PDF 批注，也不移动 Foxit 的真实文本光标；工具栏不显示逐词高亮。

只有点击“⌖ 定位”才触发页面跳转和视口调整。定位完成或超时后停止调整；朗读跨页不会自动翻页，用户可以边听边浏览其他页面。

两字同步采用插值，不能视为精确音素对齐；正文叠层受页面匹配结果影响，完整交互可靠性尚未完成验收。

## 诊断设计

默认数据目录为 `%USERPROFILE%\.lingread`，可通过 `LINGREAD_DATA_DIR` 指定。启动时创建 `diagnostic-进程号-运行标识.jsonl`，每行一条 JSON。单文件约 2 MB，保留三份轮转文件；不同运行独立记录，旧运行文件不会自动清除。

公共字段包含 UTC 时间、程序版本、进程、运行标识、启动后秒数和线程。`request` 标识一次朗读请求，`session` 标识一次播放任务，由 `playback_start` 关联；页码、句子编号和字符偏移从零计数。

| 阶段 | 记录内容 |
| --- | --- |
| 起读 | 请求、文档就绪、选区长度、复制失败原因、点击锚点与坐标匹配状态 |
| 定位 | 几何匹配状态、异常类型及起点拒绝原因；重复状态限频记录 |
| 合成 | 缓存命中、音色、语速、字符数、尝试次数、耗时、跳过原因与错误类型 |
| 播放 | 音频就绪、队列等待时间与播放完成；队列等待不等于完整可听静音时长 |
| 进程 | 每 30 秒记录内存、线程数、句柄数及状态；记录退出和未处理异常类型 |

结构化诊断采用元数据字段白名单，不记录正文、剪贴板文字、文档路径、窗口标题、截图或音频，也不自动上传。`runtime.log` 和 `crash.log` 可能含第三方异常消息及路径，分享前需检查。心跳运行于 Qt 主线程，主线程阻塞也会暂停心跳，因此缺少心跳本身不能证明死锁。

## 便携交付

使用 Python 3.12 和 PyInstaller，以 `LingReadStandalone.spec` 构建单文件 `dist/LingRead.exe`，嵌入 Python 及音频原生依赖。目标电脑无需安装 Python。`tools/package_portable.py` 负责构建、按清单收集源码、检查已知本地路径、生成文件哈希和发布 ZIP；路径检查不能替代对新增内容的隐私审查。

仅提供便携版。发布包排除个人文档、历史对话、日志、缓存和配置；`backups` 不参与修改或发布。

## 文档路径兜底

自动识别无结果或候选存在歧义时，弹出 PDF 文件选择框。用户选择当前 Foxit 显示的文件后，仅关联当前窗口、进程和标题，不立即朗读；用户回到正文重新点击或圈选后起读。关联存于内存，下一次起读若窗口、进程或标题变化，或文件已不存在，则失效。同名标签页仍无法仅凭窗口标题区分。此机制不依赖某个 Foxit 版本的注册表布局，也不自动修改 Foxit 视口。

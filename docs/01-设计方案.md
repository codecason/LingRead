## 2. 关键调研结论

### 2.1 Foxit Reader 插件机制（决定架构选型）

调研确认的事实：

1. **Foxit Reader / Foxit PDF Editor 的插件是 `.fpi` 文件**（本质是 DLL），放置在 `C:\Program Files (x86)\Foxit Software\Foxit Reader\plugins\` 目录，由 `PlgDynLoader.fpi` 动态加载管理。安装/卸载可通过 Foxit 的"帮助 → About Foxit Plug-Ins"界面或直接增删 `.fpi` 文件完成。
2. **官方开发包是「Foxit PDF Editor Plug-in SDK」（C++）**，支持给 Foxit Reader 和 Editor 添加菜单项、工具栏按钮、访问文档内容与选择区域。**但插件需要 Foxit 颁发的授权证书才能被加载**（"插件授权认证机制"），属于商业合作范畴，个人/toC 独立开发者拿不到或成本高。
3. Foxit 历史上就有官方 "Read Out Loud Plug-in"（基于 SAPI 5），说明朗读场景在 Foxit 生态内成立，但官方实现停留在老式 SAPI 合成音，自然度远低于现代神经 TTS——这正是聆阅的产品空间。

**结论：主路线采用「进程外伴侣应用」架构**——不与 Foxit 进程耦合、不需要 Foxit 授权、不随 Foxit 升级而崩溃；通过 Windows UI Automation + 文件级 PDF 解析获得与插件等价的体验。**官方 .fpi 插件作为 Phase 3 可选增强**（若未来与 Foxit 建立合作或面向企业版）。

### 2.2 TTS 成本（2026 年核实）

| 引擎 | 成本 | 自然度 | 首包延迟 | 是否满足 <0.1元/千字 |
|------|------|--------|----------|----------|
| **edge-tts**（开源，微软 Edge 在线朗读接口封装） | **0 元** | 高（神经音色，晓晓/云希等） | ~300-500ms | ✅ 默认引擎 |
| **Azure TTS** | 免费层 50 万字符/月；超出约 0.10 元/千字 | 高 | ~120ms | ✅ 边界满足 |
| **腾讯云长文本标准音色** | 预付费低至 0.75 元/万字 = **0.075 元/千字**；基础音色有 800 万字符免费额度 | 中高 | ~300ms | ✅ 付费备用首选 |
| 火山引擎 TTS | 1.3 元/千字 | 最高（9/10） | 300-400ms | ❌ 仅作付费音质升级项 |
| 阿里云长文本 | 1.6-2.2 元/万字 = 0.16-0.22 元/千字 | 中高 | 500ms+ | ❌ 不采用 |
| **Piper / sherpa-onnx**（本地 ONNX 推理） | **0 元**（离线） | 中（可接受，不如云端神经音色） | CPU 实时 | ✅ 离线兜底 |

**成本设计**：默认 edge-tts（0 成本）→ 离线时自动切 Piper 本地引擎 → 用户可选绑定自己的腾讯云 Key（0.075 元/千字，预算内）。**全部默认路径成本为 0，上限路径 0.075 元/千字，严格满足 <0.1 元/千字约束。**

## 4. 核心模块设计

### 4.1 FoxitBridge —— Foxit 交互层

职责：找到 Foxit Reader 窗口 → 拿到当前文档路径 → 确定"光标位置"。

- **窗口侦测**：枚举 `FoxitReader.exe` / `FoxitPDFReader.exe` 进程与顶层窗口；窗口标题正则提取文档名；多窗口时取前台活动窗口。
- **文档路径解析**：优先 UIA 取文档控件属性；备选从窗口标题 + 最近打开列表匹配；再通过进程句柄（NtQueryInformationProcess / Restart Manager）反查打开的文件路径，精确定位磁盘上的 PDF。

### 4.2 光标定位（需求 6 的核心）—— 三级降级策略

| 优先级 | 策略 | 精度 | 说明 |
|--------|------|------|------|
| P0 | **选区/光标同步**：监听 Foxit 选区变化，用户选中文字时悬浮条出现"从选区朗读"；选中文本经剪贴板（模拟 Ctrl+C，读完还原剪贴板）+ 在 TextEngine 的词级坐标索引中模糊匹配定位句子序号 | 句级 | 体验最佳，模拟 Acrobat "Read This Selection" |
| P1 | **UIA TextPattern**：若 Foxit 暴露 UIA 文本模式，直接取 caret 位置 | 词级 | 取决于 Foxit 版本的无障碍实现，需实测验证 |
| P2 | **当前页定位**：通过 Foxit 状态栏"第 N / M 页"（UIA 可读）拿到当前页码，从该页开头朗读 | 页级 | 保底策略，永远可用 |

**统一抽象**：三种策略最终都归一化为 `(page_index, char_offset)` 全局阅读位点，存入 ReadQueue。

### 4.3 ReadQueue —— 句子级播放队列（停止/重读/续读的基石）

- 文本清洗后按**句子切分**（中英文标点 + 语义长度上限 100 字/句），每句建立 `Sentence { id, page, char_start, char_end, text, audio_path }` 索引。
- **朗读**：从当前位点起，队列化预取——合成第 N+1、N+2 句的同时播放第 N 句（流水线），首音延迟只取决于第一句合成耗时。
- **停止 ⏹**：取消令牌置位 → 播放立即中断（≤200ms）→ 清空待发队列 → 位点停留在当前句。
- **重新读取 ↺**：位点回退到本段/本句开头，重新入队；长按回退到本次朗读起点。
- **断点记忆**：每文档 `(file_hash → last_position)` 持久化到 SQLite，下次打开同一 PDF 可"继续上次朗读"。
- **跨页处理**：位点推进自动翻页同步（可选：通过 UIA 模拟 PageDown 让 Foxit 跟随朗读翻页）。

### 4.4 TextEngine —— 文本提取与清洗

1. **提取**：PyMuPDF `get_text("dict")` 拿词级坐标（光标匹配必需）；页首/页脚/页码通过位置+重复模式识别剔除；多栏文档按坐标聚类重排阅读顺序。
2. **清洗**（直接影响自然度与准确率）：
   - 连字符断词修复（`examina-\ntion` → `examination`）
   - 中文段落内换行合并；保留段落边界作为停顿标记
   - 数字/日期/单位归一化（`2026年` → 朗读友好的 `二零二六年` 交给引擎处理，仅在引擎表现差时预转写）
   - 参考文献编号 `[12,13]`、公式占位符可选跳过
3. **OCR 兜底**：页面文本层字符数 < 阈值 → 判定扫描件 → PyMuPDF 内置 Tesseract OCR（`chi_sim+eng`），300 DPI 渲染。

### 4.5 TTSEngine —— 引擎适配层

统一接口：

```python
class TTSEngine(Protocol):
    name: str
    cost_per_1k_chars: float          # 用于成本看板
    async def synthesize(self, sentence: str, voice: VoiceConfig,
                         on_audio_chunk: Callable[[bytes], None]) -> None: ...
```

| 引擎 | 角色 | 说明 |
|------|------|------|
| `EdgeTTSEngine` | **默认** | 封装 edge-tts，流式收 chunk 即播；音色默认 `zh-CN-XiaoxiaoNeural`，可换云希/云野；支持 rate/pitch |
| `PiperEngine` | **离线兜底** | 断网/edge-tts 限流时自动降级，托盘提示用户 |
| `TencentTTSEngine` | **可选付费** | 用户填自己的 SecretId/Key，长文本接口 0.075 元/千字；设置页实时显示本月预估费用 |
| `AzureTTSEngine` | 预留 | 接口就绪，默认关闭 |

**路由策略**：本地网络探活 → edge-tts 失败/限流 → 若用户配置了腾讯云则切换 → 否则 Piper 本地。全程无感降级，朗读不中断。

### 4.6 TTSCache

- 以 `sha1(engine + voice + rate + text)` 为键缓存音频（SQLite + 文件存储），同一句重复朗读 0 成本 0 延迟。
- LRU 上限 500MB；命中统计用于成本看板（"本月合成 X 万字，缓存命中 Y%，实际消耗 Z 元"）。

### 4.7 悬浮控制条 UI（PySide6，无边框置顶）

```
┌─────────────────────────────────────────────┐
│ 🦊 聆阅 │ ▶ 从光标读 │ ⏸ │ ⏹ │ ↺ │ 1.0x │ ⚙ │
└─────────────────────────────────────────────┘
```

- 全局热键：`Ctrl+Alt+R` 从光标朗读 / `Ctrl+Alt+S` 停止 / `Ctrl+Alt+B` 重读上一句（Foxit 前台时生效）。
- 朗读时当前句在 Foxit 页面上的位置以半透明遮罩高亮（屏幕叠层窗口，利用词级坐标 × 页面缩放比换算屏幕坐标）。

## 7. 风险与对策

| 风险 | 等级 | 对策 |
|------|------|------|
| edge-tts 是非官方接口，存在限流/政策变化风险 | 高 | 引擎适配层已抽象；自动降级腾讯云/Piper；缓存降低依赖；设置页明示 |
| Foxit UIA 暴露程度因版本而异，P1 光标定位可能不可用 | 中 | 三级降级策略保证 P2 页级定位永远可用；发布前对 Foxit 2023/2024/2025 三版本实测矩阵 |
| PyMuPDF AGPL 商用合规 | 中 | 方案 A：遵守 AGPL 开源聆阅；方案 B：购 PyMuPDF 商用授权；方案 C：切换 pypdf+pdfplumber（性能略降） |
| Piper GPL-3.0 传染性 | 低 | 子进程隔离调用，或直接用 Apache-2.0 的 sherpa-onnx |
| Foxit 大版本升级导致窗口结构变化 | 低 | FoxitBridge 抽象 + 版本探测 + 灰度配置热更新 |

## 8. 验收测试计划

1. **准确率**：构建 20 份测试 PDF 集（纯中文/中英混排/多栏/扫描件/含公式表格），提取文本 CER、标定 200 句多音字测试集人工评审。
2. **自然度**：20 人 MOS 盲听（对比样本：真人录音 / edge-tts / Piper / 腾讯云），目标 ≥4.2。
3. **速度**：自动化打点脚本记录首音延迟、RTF、停止响应的 P50/P95，连续 100 次取分布。
4. **稳定性**：500 页长文档连续朗读 2 小时，监控内存/句柄泄漏；随机停止-重读 500 次自动化循环。
5. **兼容性矩阵**：Windows 10/11 × Foxit Reader 12/2023/2024/2025。

## 9. 打包 / 安装 / 卸载

- **构建**：PyInstaller one-dir（one-file 启动慢，否决）→ Inno Setup 编译单安装包 `LingRead-Setup-x.y.z.exe`（目标体积 ≤ 150MB，Piper 模型改为安装后按需下载，首装包可压到 ~60MB）。
- **安装**：写入 `Program Files\LingRead`；注册表 `HKCU\Software\LingRead`（配置）+ 标准卸载入口（设置 → 应用列表可见）；可选开机自启（默认关）。
- **卸载**：Inno 卸载器删除程序目录 + 注册表项 + 托盘退出钩子；保留用户缓存（可选勾选"同时删除朗读缓存"）。
- **升级**：安装包内嵌版本检查，支持覆盖安装保留配置与缓存。

## 附录 A：多阅读器支持（2026-09-29 增补）

### A.1 结论

聆阅的伴侣应用架构天然支持多阅读器。将 FoxitBridge 抽象为 `ReaderBridge` 接口后，**WPS PDF 可作为第二个适配器纳入支持范围，不建议"替换 Foxit"而是"两者都支持"**。增量成本约 2~3 天（M2 内消化）。

### A.2 WPS PDF 调研结论

1. **官方 JS 加载项路线不可靠**：WPS 加载项（wpsjs 工具链）主要面向文字/表格/演示组件，社区存在"PDF 标签页下 onAction 不触发"的未解决问题，且个人版/专业版支持存在版本限制。弃用。
2. **伴侣应用路线更顺**：WPS PDF 运行在独立进程 `wpspdf.exe`（与 wps.exe/et.exe/wpp.exe 分离），窗口独立、进程句柄反查文件路径更可靠，窗口侦测比 Foxit 更干净。
3. **三级光标定位策略、TTS 引擎层、播放队列、缓存、悬浮条、打包全部原样复用**，仅桥接层新增 `WpsBridge` 适配器。

### A.3 适配对照

| 适配项 | Foxit Reader | WPS PDF |
|--------|--------------|---------|
| 进程名 | `FoxitReader.exe` / `FoxitPDFReader.exe` | `wpspdf.exe` |
| 窗口结构 | 单进程多标签 | 独立进程窗口 |
| 官方插件路径 | .fpi（需 Foxit 授权） | JS 加载项（PDF 支持不可靠，弃用） |
| 差异化卖点 | 官方朗读停留在老式 SAPI | WPS 会员朗读为付费功能；聆阅免费 + 神经音色 + 光标级控制 + 断点记忆 |

### A.4 ReaderBridge 接口定义

```python
class ReaderBridge(Protocol):
    reader_name: str                      # "foxit" | "wps"
    def find_active_window(self) -> WindowInfo | None: ...
    def resolve_document_path(self, win: WindowInfo) -> Path | None: ...
    def get_cursor_position(self, win: WindowInfo) -> CursorPos | None: ...   # 三级降级内部实现
    def follow_page(self, win: WindowInfo, page: int) -> None: ...            # 朗读翻页跟随
```
